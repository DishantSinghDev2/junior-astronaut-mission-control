# Use of Super Intelligence (SI) / AI tools

This project follows the NASA Space Apps Challenge rules on SI use. SI-generated content does **not** use, contain or modify NASA logos, flags or mission identifiers. NASA pictures shown in the game are NASA's own and are displayed unchanged, with credit. This is a student project (Team Pheonix); it is not made or endorsed by NASA.

| Where | SI tool | What it did | How it is marked |
|---|---|---|---|
| **Code** (`js/*.js`, `css/`, `index.html`, `tools/`) | Claude (Anthropic) | Wrote and refactored most of the game code with Team Pheonix directing and reviewing | Header comment in every source file, `<meta name="ai-disclosure">` in `index.html`, this file, README, in-game Credits |
| **Data and text** (`js/data-events.js`, `js/lang-hi.js`, README, event texts) | Claude (Anthropic) | Drafted the event texts, the Hindi translation and documentation from public NASA material | Header comments, this file, in-game Credits |
| **Audio: narration and voice lines** (`assets/audio/intro.mp3`, `vo-*.mp3`) | ElevenLabs text-to-speech (voice "Atlas") | Spoke the script written by the team | File metadata (comment tag) says "SI-generated", this file, in-game Credits |
| **Audio: music** (`assets/audio/music-*.mp3`) | ElevenLabs Music v2.5 | Composed the lobby, exploration, storm and drop tracks from text prompts | File metadata, this file, in-game Credits |
| **Video** (`assets/video/how-to-play.mp4`) | ElevenLabs (voice), Claude (recording and overlay code) | A narrated how-to-play video. The footage is rendered by the game's own engine; the voice is SI-generated | Visible on-screen watermark "SI-ASSISTED: AI voice and AI-written code", file metadata, this file |
| **Images** | none | No images were generated by SI. All pictures are NASA photos (shown unchanged with credit) or CC0 / CC BY textures (see `assets/CREDITS.md`) | n/a |

Sound effects are synthesised live in the browser by code (no samples). 3D models are NASA, Kenney and Quaternius assets; the logos and flags on the NASA models' textures were painted out for this project.

Mars and Moon conditions (season, sunrise and sunset, Moon phase) are computed by `js/space-env.js` from published formulas; live pictures come from NASA services (SDO, EPIC, Mars 2020 raw images, NASA Image and Video Library).
